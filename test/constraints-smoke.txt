# Constraints for the lightweight import-smoke environment.
#
# The import smoke tests only need the standard library and pytest; they
# install lightweight stubs for the heavy sglang runtime dependencies
# themselves (see test/import_smoke.py and test/conftest.py).  Installing the
# full sglang dependency tree can fail during resolution on newer Python
# versions (py-spy / pybase64 / pydantic / pyzmq / quack-kernels ...), which
# aborts CI before any test runs.
#
# Use this file to keep the smoke environment minimal, e.g.:
#
#     pip install -c test/constraints-smoke.txt pytest
#     python -m pytest -q test/import_smoke_test.py -k import_smoke
#
# or, without pytest at all:
#
#     python test/import_smoke.py --bare
#     python test/import_smoke.py --selfcheck
#     python test/import_smoke.py --negative
#
# If the sglang distribution itself must be installed for other steps, use
# ``--no-deps`` so the heavy runtime dependency tree is not resolved here:
#
#     pip install --no-build-isolation --no-deps -e python
#
# Never run a bare ``pip install -e python`` as part of the smoke job: that
# resolves the full runtime dependency tree (py-spy / pybase64 / pydantic /
# pyzmq / quack-kernels / regex ...) and can abort the job before any smoke
# check runs.  The smoke checks are designed to run *before* that step and
# to keep working when it fails.
#
# It pins the smoke-only toolchain to versions that ship wheels for the
# Python interpreters used by CI (3.10-3.13).  The heavy sglang runtime
# dependency tree is deliberately NOT constrained here: the smoke checks
# never install it (see the --no-deps note above), so pinning it would only
# re-introduce the resolution failures this file exists to avoid.
#
# Keep these bounds loose enough to accept patch releases but tight enough
# to reject wheels that only exist for a different interpreter ABI (the
# cp314/cp312 mix seen in CI logs).
#
pytest>=7.4,<9
#
# It intentionally pins nothing else: it exists so that a caller can pass
# ``-c`` and, if desired, add exclusions here without touching .github/.
#
# CI wiring note (no .github/ edits required): the smoke checks are also
# exposed as a standalone, dependency-free entry point so a CI step can run
# them *before* installing the heavy sglang runtime dependency tree:
#
#     python test/import_smoke.py --all
#
# This command only needs the standard library.  It bootstraps ``python/``
# onto ``sys.path`` and stubs genuinely missing heavy deps, so it succeeds
# even when ``pip install -e python`` has not run (or has failed).  When
# pytest is importable it additionally runs the pytest-based smoke suite
# (``test/import_smoke_test.py -k import_smoke``); when pytest is absent
# that step is skipped rather than failed, so the command is safe to run in
# a bare environment.  The pytest-based variants below remain available once
# pytest is installed:
#
#     python -m pytest -q test/import_smoke_test.py -k import_smoke
#     python -m pytest -q test/run_suite.py -k import_smoke
#
# If the environment-preparation step (``pip install -e python``) fails while
# resolving the heavy runtime dependency tree, run the smoke checks directly
# instead of aborting the job:
#
#     python test/import_smoke.py --all || true   # report, do not abort setup
#     python test/import_smoke.py --all           # gate the smoke dimension
