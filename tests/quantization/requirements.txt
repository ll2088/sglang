# Minimal dependencies for the activation-fallback suite.
#
# The module under test (python/sglang/srt/layers/quantization/
# activation_fallback.py) only uses the standard library, and conftest.py
# loads it directly from its source file. CI must install ONLY this file for
# the tests/quantization suite and must NOT run ``pip install -e python``,
# which would resolve the full sglang dependency set (py-spy, pybase64,
# pydantic, pyzmq, quack-kernels, ...) and fail during environment
# preparation.
#
# Install with:
#   pip install --no-deps -r tests/quantization/requirements.txt
# The ``--no-deps`` flag is important: it prevents pip from resolving the
# sglang package metadata (which is what triggered the CI environment
# preparation failure). pytest itself has no runtime dependency on sglang.
